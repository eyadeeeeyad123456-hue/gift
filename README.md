# هدية فرح 🎀 | Farah Scrapbook

موقع سكراب بوك تفاعلي مصمم بمشاعر دافئة، يحتوي على ذكريات، صور، مقاطع صوتية، مشغل موسيقى، ودعم للمزامنة السحابية عبر Supabase.

## المميزات ✨
- 📱 متوافق بالكامل مع الهواتف الذكية وجميع أحجام الشاشات.
- ✎ وضع تعديل مباشر محمي برمز (`20101123`).
- ☁️ مزامنة سحابية أونلاين عبر Supabase لتحديث النصوص والملصقات عبر أي جهاز.
- 🎵 مشغل أسطوانات فينيل + مشغل شريط كاسيت للأصوات.
- 🎁 تجربة هدية ومفاجأة تفاعلية.

## التشغيل محلياً 💻
```bash
node server.js
```
أو بالضغط مرتين على `start-server.bat`.
